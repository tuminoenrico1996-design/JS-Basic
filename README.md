# JS Basics – Compito di inizio settimana

### 1. Cos'è un algoritmo?

Un algoritmo è una serie di passaggi da seguire in un ordine preciso per risolvere un problema o raggiungere un obiettivo. Per esempio, quando seguiamo una ricetta di cucina, eseguiamo delle istruzioni una dopo l'altra per ottenere il piatto finale.

### 2. Cos'è una variabile?

Una variabile è una specie di contenitore a cui diamo un nome e dentro il quale possiamo salvare delle informazioni, come numeri o parole. Queste informazioni possono essere utilizzate nel programma e, se la variabile lo permette, possono anche essere modificate.

### 3. undefined e null sono la stessa cosa?

No, non sono proprio la stessa cosa.

`undefined` significa che una variabile non ha ancora ricevuto un valore, mentre `null` viene utilizzato quando vogliamo indicare intenzionalmente che un valore è vuoto o assente.

Quindi la differenza principale è che `undefined` indica un valore non assegnato, mentre `null` indica un'assenza di valore scelta volontariamente.
